# E-Commerce Order Management System

A full-stack e-commerce application built using Java, Spring Boot, Angular, MySQL, and Docker. The project uses a microservices architecture to manage users, products, orders, payments, and shopping cart operations.

## Tech Stack

- **Backend:** Java 17, Spring Boot, Spring Security, Spring Data JPA
- **Frontend:** Angular 17, TypeScript, HTML, CSS
- **Database:** MySQL 8.0
- **Microservices Communication:** REST APIs, Apache Kafka
- **Authentication:** JWT
- **Deployment:** Docker, Docker Compose
- **Testing:** JUnit, Mockito
- **Build Tools:** Maven, npm

## Features

- User registration and login
- JWT-based authentication and authorization
- Product listing and management
- Shopping cart operations
- Order creation and management
- Payment processing integration
- RESTful APIs
- Microservices-based architecture
- MySQL database integration
- Docker-based application setup
- Unit testing with JUnit and Mockito

## Architecture

The application consists of the following components:

- **API Gateway:** Routes requests to the appropriate services.
- **User Service:** Manages user registration and account information.
- **Product Service:** Handles product information.
- **Cart Service:** Manages shopping cart operations.
- **Order Service:** Handles order creation and tracking.
- **Payment Service:** Manages payment-related operations.
- **Notification Service:** Handles order-related notifications.
- **Angular Frontend:** Provides the user interface.

## Prerequisites

Install the following before running the project:

- Java 17
- Node.js and npm
- Angular CLI
- Docker Desktop
- Git
